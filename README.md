# Jam Nail Spa

React + TypeScript + Vite + Tailwind CSS starter with empty Navbar and Hero components on a white background.

## Development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Fonts

Google Fonts: DM Sans, Montserrat, and Playfair Display.
Local fonts: Ngetic Modern Regular and Italic in `public/fonts`.

Tailwind font utilities: `font-sans`, `font-montserrat`, `font-playfair`, and `font-ngetic`.
Use `font-ngetic italic` for Ngetic Modern Italic.
